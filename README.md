# Simple Crosshair

A lightweight, transparent overlay application for Windows that displays a simple, non-interactive crosshair in the center of your screen.

## Installation

Go to the [Releases page](https://github.com/luzdivina-s7n/simple-crosshair/releases) and download the latest version, or build it yourself by running `build.bat`.

## Features

- Minimal CPU and memory usage.
- Stays visible over your applications and games.
- Does not capture mouse clicks or interfere with game inputs.
- Change the size of the crosshair via the system tray icon.

## How to Use

1. Run `simple-crosshair.exe`.
2. The crosshair will appear right in the center of your display.
3. Access the system tray icon in the bottom right corner of the taskbar to adjust the size or exit the application.

## System Requirements

- **OS:** Windows
- **Runtime:** .NET Framework 4.0 or higher
